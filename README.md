# AgnosticFL

Framework-agnostic federated learning hub: hospitals keep their own framework (NVFlare, vantage6, Flower); a central hub runs FedAvg across all of them through per-framework adapters speaking the `flhub/0.1` protocol.

Status: under construction. See `docs/agents/PROJECT_PLAN.md` for the plan and `REPORT.md` (when finished) for results.
